# MyIncrediblePortfolio

MyIncrediblePortfolio is my personal portfolio website, created to showcase my projects and share my interests in programming, photography, and technology.

## About the Project

I built this website to put my web development skills into practice and create a personal space to present my work. It has been an opportunity to experiment with HTML, CSS, JavaScript, and web design while learning how to turn my ideas into a working project.

I'm also participating in **Hack Club Terra**, a YSWS (You Ship We Ship) program by Hack Club.

The portfolio includes a personal introduction, a photography section, and projects such as CleanBench PSU, Didup Plus, and D-Desk.

## Getting Started

**Visit the live website:** [MyIncrediblePortfolio](https://fedevxyz.github.io/MyIncrediblePortfolio/)

### Run Locally

Make sure you have [Node.js](https://nodejs.org/) and npm installed.

Clone the repository and install the dependencies:

```bash
git clone https://github.com/fedevxyz/myincredibleportfolio.git
cd myincredibleportfolio
npm install
```
Start the development server:
```bash
npm start
```
To build the project for production:
```bash
npm run build
```
